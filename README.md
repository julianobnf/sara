# SARA — Sistema Automático de Relatórios de Adaptação

O SARA é um sistema web que automatiza a criação de relatórios de adaptação de materiais acessíveis.  
Permite registrar tipo de material, referência bibliográfica, créditos e data de adaptação, gerar uma visualização padronizada com template institucional e exportar o relatório final em PDF no formato A4.

O sistema foi pensado para apoiar fluxos de trabalho ligados à acessibilidade informacional, especialmente em contextos de bibliotecas, repositórios e serviços de apoio à inclusão.

---

## Funcionalidades

- Formulário simples para preenchimento dos dados do material  
- Adição de múltiplos responsáveis e funções de adaptação  
- Geração automática do relatório em layout padronizado  
- Visualização prévia antes do download  
- Exportação em PDF (A4)  
- Possibilidade de personalizar o template visual  

---

## Tecnologias

- HTML  
- CSS (TailwindCSS via CDN)  
- JavaScript  
- html2canvas  
- jsPDF  

---

## Como usar

1. Abra o arquivo HTML no navegador  
2. Preencha os campos do formulário  
3. Gere o relatório  
4. Faça o download do PDF  

O sistema pode ser usado como página independente ou incorporado em outros sites via iframe.
